## Critical data-layout correction
Desktop wrappers use:
- Windows: `DCP-UserData/Windows`
- macOS: `DCP-UserData/macOS`
- Linux: `DCP-UserData/Linux`

Legacy Windows install stores SQLite and master key under `platform/data` and `platform/storage`. An installer that simply copied them back to those old paths would silently start a blank profile. DC06 updates all online installers:
- Windows installer gracefully closes DCP, preserves `DCP-UserData`, backs up old app root, migrates legacy DB/storage into `DCP-UserData/Windows`, and compares SQLite/master-key SHA-256 before launch.
- macOS installer preserves `DCP-UserData` and migrates legacy data/storage into `DCP-UserData/macOS`.
- Linux installer preserves `DCP-UserData` and migrates legacy data/storage into `DCP-UserData/Linux`.
- All migration paths prefer an existing new-layout database/key; legacy data is copied only if the target database/key is absent.
- Windows/Linux/macOS package builders and CI now stage/check per-OS user-data folders and ensure actual DB/key files are not shipped.
